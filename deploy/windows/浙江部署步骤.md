# 浙江台风智能体 Windows 原生部署步骤（v1.4.10）

本部署包直接使用 Python 虚拟环境运行，不需要安装 Docker。

## 一、目标电脑要求

- Windows 10、Windows 11 或 Windows Server 64 位；
- 64 位 Python 3.11，安装时建议勾选 `Add Python to PATH`；
- 建议至少 4 核 CPU、8 GB 内存、5 GB 可用磁盘；
- 使用 DeepSeek 和联网检索时，服务器需要能够访问外部 HTTPS（443端口）；
- 推荐使用新版 Chrome 或 Edge，旧版 Internet Explorer 不受支持。

## 二、解压和进入目录

将压缩包完整解压，例如：

```text
D:\zhejiang_typhoon_agent_windows
```

打开 PowerShell：

```powershell
cd D:\zhejiang_typhoon_agent_windows\app
Set-ExecutionPolicy -Scope Process Bypass
```

`Set-ExecutionPolicy -Scope Process Bypass` 只对当前 PowerShell 窗口生效，不修改系统永久策略。

## 三、安装环境

部署包已附带 Python 3.11 Windows x64 离线依赖，推荐执行：

```powershell
.\deploy\windows\install.ps1 `
  -Offline `
  -Wheelhouse ..\wheelhouse_py311_win64
```

如果目标电脑能够访问 PyPI，也可以联网安装：

```powershell
.\deploy\windows\install.ps1
```

如果没有 `py` 命令，可指定 Python：

```powershell
.\deploy\windows\install.ps1 -PythonCommand "C:\Program Files\Python311\python.exe"
```

安装脚本会自动创建 `app\.venv` 并生成 `app\.env`。启动脚本会直接使用 `.venv`，不要求手动激活。

## 四、配置 DeepSeek、天地图和应用

打开配置：

```powershell
notepad .env
```

至少填写：

```dotenv
DEEPSEEK_API_KEY=目标电脑使用的有效密钥
DEEPSEEK_BASE_URL=https://api.deepseek.com
DEEPSEEK_MODEL=deepseek-v4-flash
TIANDITU_API_KEY=申请到的天地图浏览器端Key
```

天地图 Key 在 `https://console.tianditu.gov.cn/` 申请。请选择浏览器端/Web应用类型；如果控制台要求配置访问来源，请加入实际访问使用的服务器内网IP或正式域名。天地图 Key 会随浏览器图块请求发送，不应当作服务端秘密；建议在天地图控制台限制可用来源。

两个 Key 配置一次即可，后续每次启动都会读取 `.env`，不需要重复输入。不要把填写 DeepSeek 密钥后的 `.env` 发送给其他人。

本机使用时保持：

```dotenv
APP_HOST=127.0.0.1
APP_PORT=8766
```

知识库文件已随包提供：

```text
app\typhoon\data\typhoon_history.sqlite3
app\typhoon\data\typhoon_rag.sqlite3
```

运行账户必须对这两个文件及其目录具有读写权限，网页上传知识文件时会更新 RAG 数据库。

## 五、启动

```powershell
cd D:\zhejiang_typhoon_agent_windows\app
Set-ExecutionPolicy -Scope Process Bypass
.\deploy\windows\start.ps1
```

成功时出现：

```text
Production server listening on http://127.0.0.1:8766
Health check: /api/typhoon/status
```

保持该窗口运行，在 Chrome 或 Edge 打开：

```text
http://127.0.0.1:8766
```

如果轨迹存在但地图底图不显示，先打开 `http://127.0.0.1:8766/api/map/config`，确认 `configured` 为 `true`，再检查目标电脑是否可以访问 `tianditu.gov.cn:443`。修改 Key 后必须重启服务。

## 六、验收

另开一个 PowerShell：

```powershell
cd D:\zhejiang_typhoon_agent_windows\app
Set-ExecutionPolicy -Scope Process Bypass
.\deploy\windows\test.ps1
```

应返回 `analogue_count : 10`、`fact_validation : pass`。状态接口中的 `rag.available` 应为 `true`。

如果 `used_mode=template`、`fallback=True`，说明路径检索成功但 DeepSeek 没有调用成功，请检查 `.env`、密钥和外网连通性。

## 七、让同一局域网的其他电脑访问

将 `.env` 修改为：

```dotenv
APP_HOST=0.0.0.0
```

按 `Ctrl+C` 停止服务后重新执行 `start.ps1`。以管理员身份打开 PowerShell，执行：

```powershell
cd D:\zhejiang_typhoon_agent_windows\app
Set-ExecutionPolicy -Scope Process Bypass
.\deploy\windows\enable_lan_access.ps1
```

查询部署电脑地址：

```powershell
ipconfig
```

假设 IPv4 是 `10.10.13.210`，同一可互通内网中的其他电脑使用 Chrome 或 Edge 打开：

```text
http://10.10.13.210:8766
```

其他电脑无需安装 Python或复制项目，只需要浏览器，并能访问部署电脑的 IP 和端口。不同 VLAN 或不在同一局域网时，需要网络管理员配置路由和访问策略。

停止共享时，以管理员身份执行：

```powershell
.\deploy\windows\disable_lan_access.ps1
```

不要把 8766 端口直接暴露到公网。正式外网访问应通过单位的 IIS/API 网关、HTTPS、认证、白名单和限流。

## 八、功能验证建议

1. 上传 `app\typhoon\examples\bavi_2020_real_full_track_test.json`，检查是否返回10个相似台风。
2. 选择历史台风后继续追问。
3. 输入有轻微错字的问题，例如“台风强度汝河”，系统应先由 DeepSeek 归一为“台风强度如何”，再检索知识库。
4. 询问“浙江省采取了哪些应对措施”，应关联应急响应、防御措施、预警发布、会商和值班值守等表述。
5. 本地证据不足时应自动联网；只有搜索摘要时不会声称已阅读全文。
6. 点击“退出该台风对话”，再询问“今年浙江登陆了几个台风”；系统应按服务器当前日期解析“今年”，联网检索、调用 DeepSeek 精炼，并显示可点击来源。
7. 选择明确在浙江登陆的历史台风时，界面应先显示登陆地点；几何距离仅标注为“轨迹采样点至浙江参考边界的最小计算距离”，不再表述成尚未登陆浙江。

## 九、常见问题

### PowerShell 禁止运行脚本

在当前窗口执行：

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass -Force
```

### 页面能打开但按钮无反应

使用新版 Chrome 或 Edge，并按 `Ctrl+F5` 强制刷新。不要使用 Internet Explorer。

### 无法调用 DeepSeek

```powershell
Test-NetConnection api.deepseek.com -Port 443
```

同时确认 `.env` 中密钥、地址和模型编码正确，修改后必须重启服务。

### 更新或备份

更新前至少备份：

```text
app\.env
app\typhoon\data\typhoon_history.sqlite3
app\typhoon\data\typhoon_rag.sqlite3
```

其中 `.env` 保存部署配置和密钥，不能放入公共压缩包；两个 SQLite 文件保存正式知识库。

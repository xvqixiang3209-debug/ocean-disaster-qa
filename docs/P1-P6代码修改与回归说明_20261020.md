# P1–P6代码修改与离线回归说明

本轮在现有 DeepSeek、CRAG 和业务计算模块上完成了 P1–P6 的首轮代码实现及离线回归。新增流程处理的是子问分类、证据归属、局部恢复、缺项范围和关系校验这些通用环节，没有按 G3、A2、C3、M1 的题号配置答案。

实现目录：`E:\ocean_qa\ocean_phase1_20261006\app`。

## 修改内容

| 阶段 | 实际修改 | 关键边界 |
|---|---|---|
| P1 子问契约 | `facet_contract.py` 统一子问ID、类型、对象、地点角色、时间和所需交付；检索、生成、审查与局部恢复复用契约。`conversation.py` 保存输入状态，显式更正替换旧地点、日期和台风。网页检索、NC获取及点序列缓存加入输入状态指纹。 | 历史回答只用于理解追问；重新检索取得的资料才是事实证据。 |
| P2 证据与文档卡 | `evidence_units.py` 分开正文和文件身份，记录章节、原文偏移、段落哈希、文档卡哈希。CRAG、生成和审查复用稳定段号。普通解码及分型校验分别处理段号0与正文段。 | 标题、机关和日期只能证明文件身份；程序、金额、资格及职责需要正文。施行日不能冒充印发日。 |
| P3 局部恢复 | `typed_grounding.py` 在删句前锁定原子陈述的对象和子问；分号等可安全拆分处独立校验，条件与否定保持整体。区分正文事实、文件身份、受约束归纳、计算、缺项和范围说明；同一陈述判定冲突最多复核一次。`recovery.py` 冻结已核对内容，最多定向补检一次、局部重写一次。 | 归纳仅开放有完整前提支持的同属性比较；不靠实体共现批准新因果、许可或普遍规则。前提及新原子ID一起重映射。 |
| P4 缺项范围 | `scope_gate.py` 精确处理覆盖审查标出的额外缺项，保护真实数值、个人资格、当日状态、现行版本和当地办理要求。通用方法不因出现地名而要求当地已采纳文件；科普页不因标题有“预报”就必须具备预报有效期。 | 删掉缺项不自动升级为完整回答。新的、同地点同日期且完整的已核对数值或状态可以消解原缺项；资格、许可、现场安全等不能据此消解。 |
| P5 关系守卫 | `relation_guard.py` 检查蚊媒/鼠类及污染水接触关系混淆、联合主语在防蚊语境下造成的误读、部分提出建议/审批主体错配及未问配药却给剂量。医学关系优先卫生健康或疾控来源。 | 官方词表只用于发现错误，不作为新答案证据。命中后保留其他有据内容，并局部重查；不能凭词表自动补写疾病关系。 |
| P6 正文提取 | `web_supplement.py` 保留原文顺序和章节，不把施行日期前置；增加疾控官方替代来源、附件身份继承、原始响应及有界正文快照、旧采集件复核标记、无关路径页过滤。 | 未绕过网站访问限制；读取时间不冒充发布时间，历史采集件不自动变成现行文件。 |

主流程接入位于 `qa.py`、`crag.py`、`answer_pipeline.py`、`chat_api.py`。每题在新路径下共享最多10次模型调用和60秒后不再启动新步骤的预算；单次调用不自动重试。已经发出的网络请求仍可能在其超时范围内结束，因此这里没有宣称线程或网络层面的绝对60秒完成保证。

## 验证结果

1. 正式测试目录全量运行：**1354项测试、102项子测试通过，失败0、跳过0，11.91秒**。JUnit合计1456个测试项。包含开关关闭兼容性、同类改写、地点/日期/台风更正、复合句保留、归纳负例、数值对应关系、禁止联网、预算耗尽和局部补检等用例。
2. 使用 P0 冻结源代码和原录制依赖，**24/24严格断网回放通过**；HTTP状态及实际发布的回答/错误相同。原有1次HTTP503保留，未补跑、未伪造回答。
3. 新程序重新处理24次录制里的**59份真实旧草稿、836个原子片段**，全部满足规范化草稿的精确连续原文约束；冬春救助办理段不会因前段被删除而改归过渡期救助。
4. 对**53次旧覆盖审查**进行确定性范围处理，55处经审查明确定位的缺项条目被移除；只有1个完整的纯限制语单元可以直接从旧正文安全移除。55是多轮审查中的出现次数，不是55道题；混有事实的段落保持原样，交由新路径局部生成及分型校验处理。
5. 关系守卫对8份旧草稿产生15处待复核警报。这是检测信号，不能当作15条已经经专家确认的错误，也不能当作新版实际回答效果。
6. 23份可用生成证据的新版视图重复构建，段号和哈希一致；另1题在生成前连接失败。
7. 预览启动脚本通过 PowerShell 语法解析，未启动新服务、未重启现有服务。

详细逐题报告：`exports/P1-P6代码改造_24次录制离线回归与对照_20261020.html`；配套JSON保留各题旧实际回答、检查输入及确定性处理记录。

## 离线回归能证明什么

冻结旧代码回放证明录制依赖完整、旧结果可复现。新程序对旧草稿和审查意见的处理证明偏移、归属、缺项闸门、关系警报及片段发布门槛的程序行为。集成测试中的新分型模型意见使用明确标注的合成依赖，不冒充真实DeepSeek输出。

本轮**新增DeepSeek调用为0**，没有把旧版逐句判定转换成新版模型判定，没有重跑160题，也没有计算“新版完整正确率”。新版提示词下的真实回答、延时和费用仍待后续获准的在线验证。独立人工业务评审也未完成。子问分类和关系守卫目前是确定性规则及受约束判定，不能证明已覆盖所有自然语言表达。

离线回归过程没有联网。连接器另做了免费官方网页读取校验：中国疾控中心《2026年5月健康风险提示》和《自然灾害传染病防控技术指南》均返回HTTP200，正文分别2665、44422字。它们证明可获取这些资料，不代表当天当地有疫情。关系词表每条保留官方URL、取得日期、核对方式及摘段哈希，未冒称医疗专家审定。

## 启用与回滚

按照方案要求，新功能默认关闭，现有服务不会因为文件修改自动切换。已提供独立预览脚本，避免与8769现有服务冲突：

```powershell
cd E:\ocean_qa\ocean_phase1_20261006\app
powershell -ExecutionPolicy Bypass -File .\start_p1_p6_preview.ps1
```

该命令启动8770端口，页面为 `http://127.0.0.1:8770/`。启动本身不等于新增问答授权；实际提交问题会按配置调用模型并产生API费用。本轮没有运行该启动命令。

预览配置打开 `MARINE_FACET_CONTRACT`、`MARINE_EVIDENCE_UNITS`、`MARINE_SCOPE_GATE`、`MARINE_CONNECTOR_V2`，将 `MARINE_TYPED_GROUNDING` 和 `MARINE_RELATION_GUARD` 设为 `on`。脚本退出后恢复原进程环境变量。`-Grounding shadow` 可记录分型校验结果而保持原回答发布路径。

关闭新进程后用原启动脚本即可回到旧路径。原始代码备份位于 `E:\ocean_qa\implementation_backups\20261020_p1_p6`；P0真实录制、授权快照与冻结源代码仍只保留本机，未上传公共仓库。

# 本地数据资产与快照运行边界

本仓库可以审阅代码和重放记录，也包含临时 fixture 与 mock 的程序测试。它没有本机业务大库及授权凭据，无法直接复现完整的本地检索、历史台风地图数据、任意时段 NC 计算或收费模型回答。恢复数据只在受控本地环境进行，不将私人数据或凭据提交 Git。

## 已包含

- `data/requirements/catalog.json`：160 题需求目录。
- `data/public_references/manifest.json` 与宁波公共巨灾保险公开 PDF、核对摘录及更正记录：正文提取、哈希与来源校验测试用。原始 PDF 与摘录保持原哈希；未包含未核验 OCR 全文。`manifest` 中的原始 OCR 文件引用是历史处理轨迹，不表示这些文件在仓库中。
- Leaflet 静态资产和 LICENSE，以及少量公开台风编号映射。
- 脱敏实际回答、官方网页必要片段和失败诊断。

- `exports/浙江沿海活动官方规则表_20261017.json` 和 `.txt`：现有测试所依赖的官方活动规则导出 fixture，保持与代码中的政策目录一致；不表示任意地点或日期活动已获许可。

## 未上传及恢复位置

| 资产 | 原项目相对路径 | 本地恢复用途 |
|---|---|---|
| 文档知识库 | `data/marine_kb/knowledge.sqlite3`、`data/marine_kb/files/` | 本地切片、索引、原件打开、审核与授权 |

| 历史台风与灾害 | `typhoon/data/typhoon_history.sqlite3`、`typhoon_rag.sqlite3` | 路径与指标检索、案例比较 |

只读盘点在 `local_asset_inventory.json`。恢复时将数据放在同名相对目录，并使用原项目初始化脚本或迁移机制；不要把空模板库覆盖已有业务库。源代码包含既有本机默认路径，异机运行先核对 `config.py`、各模块配置与所需目录。

## 联调条件

1. 默认不启用外部模型与下载 worker；单元测试和源码分析不需要真实 API 密钥。
2. 真实问答需自行设置 DeepSeek/搜索服务等授权配置，并核对资料外发范围。账户已配置不等于所有知识库资料都可以外发。
3. 网页正文不可达、令牌缺失、NC 不覆盖指定时间、单位未知分别记录，不能回退成伪造数据。公开网页变化会影响可重复性，保存取得时刻、原文哈希、URL 与文档版本。
4. 查询“截至某日”时同时约束资料取得/发布时间与有效时间，防止使用未来起报批次回答过去预测问题。
5. SWL、风速单位、高程基准、岸段阈值版本和台风场景归属等历史假设继续显式标注；未经核定不升级成正式业务结论。

## 不随快照发布的内容

真实 `.env`、API key、访问令牌、浏览器 Cookie、会话 ID、私人路径、未授权原始资料、OCR 全文、SQLite、NC、GeoTIFF、ZIP、下载缓存、运行日志及屏幕截图。评测保留实际回答，原本地切片仅保留来源元信息。公开附件保留来源与版权归属，没有为业务资料新增分发许可。

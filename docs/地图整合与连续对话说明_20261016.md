# 历史台风地图与连续问答

版本：phase1.3.0-map-conversation；更新日期：2026年10月16日。

## 打开和使用

2026年10月19日入口更新：当前新版打开 http://127.0.0.1:8769/ ，首页标题与原“台风类比”标签统一为“海洋灾害知识问答”，所有提问与连续追问在地图右侧完成。“简洁问答”入口已移除；旧 /chat 与 /chat.html 自动跳转首页，/map 仍打开同一个地图问答页面。原地图工具和资料管理入口继续保留。

在右侧输入问题后按 Enter 发送，Shift+Enter 换行。回答完成后，直接输入下一句即可连续追问，不需要复制上一个问题。回答支持标题、步骤、加粗和表格；参考来源默认折叠，可展开查看原文。

可以按以下顺序体验：

1. 问“什么是风暴增水？它和天文潮有什么关系？”；继续问“你刚才说的叠加，是不是把两个最大值直接相加？”
2. 问“浙江海洋灾害应急响应终止由谁决定？请分步骤说明。”；继续问“第二步具体由谁批准？”；再问“那上海呢？”
3. 在地图选择2019年利奇马后，问“最大增水是多少，出现在什么站？”；继续问“这个站还有哪些相关记录？”

地图所选台风为省略对象的案例提问补充身份。明确提出其他台风、年份、地区或完整的新概念问题时，按本轮问题查询。切换或退出台风案例会重置后续问答上下文，页面保留此前回答供查看。点击“新建对话”清空问答显示和服务端对话记忆，同时保留地图选择。

## 对话如何处理

服务端保存当前浏览器的最近6轮成功对话，结合上一轮实际回答解析“这个站”“第二点”等指代，再围绕改写后的本轮问题重新检索资料库和官方网页，由现有DeepSeek服务组织回答。先前回答仅用于识别提问对象和步骤，不充当新答案的事实证据。序号追问按上一轮实际编号对应的动作解析，避免把“提出建议”误认成“批准”。

会话采用浏览器归属校验；页面不能提交伪造的历史回答。资料撤回或外发权限变更后，相关旧回答会重新检查是否可用于模型上下文。失败的生成不计入有效历史；切换案例、清空对话后到达的旧请求结果不会写回新对话。

历史会话暂存在服务内存，连续2小时未使用后失效，服务重启后清空；最多保留256个会话。这里的“连续对话”指当前使用过程的上下文承接，尚未实现账号下跨设备、跨重启的聊天记录恢复。

已有分站、超警及路径等专用查询继续通过历史台风业务服务处理。模式工作簿缺少单位、基准或阈值等说明时，仍按原数据边界处理，连续对话不会补造缺失数值。

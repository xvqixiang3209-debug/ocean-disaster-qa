# 全局回答结构与每题联网检索说明

版本：phase1.2.9-always-hybrid-qa；日期：2026-10-16。

## 默认流程

普通专业问答统一执行：问题规范化与子问题拆分 → 并行查询资料库和官方网络 → 对正文做相关性与子问题覆盖排序、去重 → 选择最多4份本地片段和4篇网页正文 → DeepSeek综合组织回答 → 引用、数值、版本和可读性检查。

本地已经有答案，也执行网络搜索；不再先生成本地答案来决定是否联网。普通问答每次调用都会刷新搜索，不仅返回此前的补查缓存。未匹配到合适正文时不凑数量，也不强行将无关网页加进回答。网络失败时仍可用已获准的本地证据生成回答。

该默认流程由生产环境的共享MarineQuestionService承担，适用于简洁问答页、知识工作台、普通聊天接口和选定台风后的普通事实问答。分站表、路径相似度等业务计算继续使用专业数据流程；模式表必要字典未确认时，保持计算限制，不能用其他网页数值替代。

显式关闭联网或外部模型仍受尊重。程序内部保留local_first参数用于兼容测试，生产服务固定采用always。

## 所有普通问答的结构

统一要求是“先直接回答，再解释依据”，不把每一道题硬套成同一个四段模板。

| 问题类型 | 默认组织方式 |
|---|---|
| 概念定义 | 通俗定义 → 必要解释 → 另外问到的关系或影响 |
| 比较区别 | 核心区别 → 同维度要点或表格 → 用户关心的选择 |
| 数据查询 | 数值和地点 → 时间、单位、基准 → 必要来源差异 |
| 历史案例 | 指定事件的答案 → 相关事实或实际行动 → 历史口径 |
| 条件与程序 | 判断框架 → 条件及决定主体 → 编号步骤 → 适用文件 |
| 避险与行动 | 最重要行动 → 按优先级列步骤 → 场景限制 |
| 当前情况 | 截至时间与可确认情况 → 地点和有效时段 → 必要下一步 |
| 产品查询 | 查询入口或产品 → 获取步骤 → 产品时间与范围 |
| 成因与影响 | 直接原因或关系 → 因果解释 → 适用条件 |
| 季节规律 | 季节限制是否成立 → 常年时段与地区 → 防范重点 |
| 计算方法 | 有据方法 → 公式、变量和单位 → 计算步骤或缺项 |

复合问题保留每个实际子问题的覆盖状态。未问到的全部地区、所有年份、复杂温盐阈值或当前实况，不应自动扩大成用户的需求。重复的归档标签、文件缺项报告和无关案例会触发一次表达修复；已有通过证据检查的草稿不会因表达修复失败而被丢弃。

## 联网与证据筛选

- 搜索只使用公开主题、明确的公开台风身份、年份、地区和意图。资料原文、原文件路径和聊天历史不进入搜索词。
- 搜索域名操作符不再参与主题相关性匹配，避免网址后缀如com让无关结果提前通过。非台风主题也不会被错误扩展为“主题＋台风”。
- 读取官方正文后，再按问题相关性和子问题覆盖排序；重复网页、无关灾种和没有正文的搜索摘要不作为回答依据。
- 一部分基础知识与预案有官方来源地址索引。每次仍实际读取、检查和筛选正文；索引不储存预制答案。
- 官方附件与印发通知保持关联，保留落款日期和废止条款；不能把被废止的2022版年份当成2026年新文件年份。
- 支持在原有下载上限内读取gzip/deflate压缩正文，解压后也有大小上限；公网、重定向、TLS和robots规则继续校验。
- 2026-10-17补充浙江海洋业务来源`zjocean.org.cn`与海星轮船运营来源`hxzs.com.cn`。浙江当前海洋预报/预警、舟山客运停复航问题增加相应站点检索；域名按完整边界匹配，伪造相似域与跳转到非可信域仍不采用。海星公告用于运营方发布的航线安排，不作为政府响应命令。
- 网页搜索与正文读取不等于公告有效状态核验已完成。目前保留发布时间和读取时间，动态非预案来源还做新旧过滤，但尚未完整建立公告生效、解除、替代及航线/航次状态关系。查到公告后仍按正文的地区、对象和有效时段解释；未查到有效证据不能推定已复航、已解除或允许活动。
- 原文全角小数点可规范化参与数值校验，不改变原文引用；米与厘米的精确等价只用于解释单位，不合并站点、时刻、基准或口径。

## 验证与实际限制

- Python回归：176项测试、21个子测试通过。
- 前端检查：标题、步骤、加粗、表格、安全文本渲染及高级工作台内联JavaScript语法通过。
- 实测使用真实DeepSeek、获准本地材料和公开来源；结果见`exports/全局混合检索_20题实测记录_20261016.md`。
- 20题及定向复测的合并记录：19道普通问答均执行网络搜索；18题生成回答，2题因计算字典或有效实时资料不足保留缺口。首轮1道季节题触发输出检查保护，启用DeepSeek JSON输出模式并修正检索路线后复测通过。
- 问题规划与结构化回答使用JSON输出模式，并为引用/数值修复提供明确错误诊断；引用与证据检查没有关闭。
- 网络来源可能访问失败、限流或没有匹配正文。“每次搜索”不保证每题都有联网证据，更不证明所有回答完全准确。缺资料或版本不明时仍如实保留对应缺口。
- 本次未重新尝试此前被拒绝的浏览器页面访问，因此没有新增网页可视检查或截图验证。

## 使用

服务入口仍为`http://127.0.0.1:8767/`。重启服务后刷新页面、重新提问即可；无需重新导入资料，旧回答不会自动改写。

复测命令：`..\.venv\Scripts\python.exe tools/verify_answer_clarity.py`。定向复测可追加`--ids 1 6 16`；会真实调用模型及网络服务。

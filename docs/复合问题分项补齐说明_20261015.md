# 复合问题分项补齐

版本：phase1.2.7-subquestion-hybrid-qa。

将用户问题拆成最多6个实际子问题，每项记录full、partial、insufficient及对应证据编号。每项都有依据才能判为整题已覆盖；一个子问题有资料不代表全部已覆盖。未返回逐项覆盖信息的复合问题会保守地转入补充检索。

本地可回答的部分保留；只将未完成子问题的公共主题和意图用于联网搜索。决定主体、启动条件、公告程序等缺项分别构造搜索词，不能用同一条长查询掩盖其他子问题。最后将本地保留证据与成功读取的权威网页正文合并，按子问题顺序生成最终答案，并重新检查引用与逐项覆盖。

长网页按各子问题分配证据空间；不再仅截取开头。真实联调发现杭州2022年五停指导意见的决定程序和信息渠道位于正文后部，旧截取方式导致这些段落没有进入生成上下文。现已针对其段落选择增加回归测试。

相关段落节选与全文读取范围分别标记，不能因本次节选未覆盖某项规定就宣称原文件没有该规定。

政策题明确地区及文件版本。未指定具体城市时，可用明确标注地区、版本的地方文件作示例，不能作为全国或全省统一规则。系统业务默认范围为浙江。不同地区五停名称和内容可能不同，执行通告不能冒充通用规范。实际仍缺的子项保留缺项说明。

真实示例：截图问题拆为启动条件、由谁决定、怎么公告。模型首先识别本地部分缺项，然后读取杭州市2022年指导意见，将其中属地政府决定、部门落实及多渠道发布信息等内容与本地资料合并。回答保留杭州示例范围，不宣称所有地区规定已齐备。

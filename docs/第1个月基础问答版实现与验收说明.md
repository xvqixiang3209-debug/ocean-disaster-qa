## 打开与操作

普通问答入口：<http://127.0.0.1:8767/>；资料管理：<http://127.0.0.1:8767/knowledge.html>；台风地图：<http://127.0.0.1:8767/map>。

1. **资料与审核**：按文件和类别检索，查看定位正文、质量提醒、审核历史，并下载新治理库保存的原件。标准和OCR资料仍须核验，审核和外发授权分别控制。旧历史库的引用也可打开保留文本；该库未保存的原件会明确提示，不能伪称原件可下载。
2. **第1个月验收**：160题、10个主类全部登记；支持按角色、建议月份、规划范围和状态筛选。近期专业64题、通用60题、远期公众36题是依据原角色作出的规划标签，仍待业务核定。源台账建议首月窗口77题；这个数不等于已承诺或已完成77题。逐题查看子需求、来源条件和原Excel行号，保存核定依据并查看变更历史。
3. **历史预报产品**：按产品关键词、发布日期和地区查询。已打通海浪／风暴潮历史产品文件检索，目前有1637条可检索文件记录，含同一产品的DOC/PDF副本，不等于1637个独立签发时次。可查看发布／签发时间、有效时段、发布单位、属性、证据定位和原件。未知字段显示未注明，文件名日期不冒充签发时间；相对有效期保留原文，不猜绝对时段。实时产品接口仍待提供。
4. **专业问答验收**：本地检索、带编号出处的原文摘录及来源跳转可用。保留跨台风、预报/实况、年度损失和未审规范保护；修复“出现在什么站”误触实时拒答的问题。
5. **20题业务验收**：在首月页下方逐题核验已记录回答，填写验收人、专家参考答案、原件出处及意见，再评定事实、完整性、引用和时间口径。只有核定样本、具备答案与证据且四项合格才可记通过。记录留痕；回答或候选清单变化后，旧评分失效并要求重评。不会自动把候选子问题成绩转成原题完成状态。

## 接口与复跑

接口均沿用本机访问边界，写操作须带服务端签发的X-Knowledge-Token。

- GET /api/knowledge/requirements：支持q/category/month/role/scope/status/page/limit。
- POST /api/knowledge/requirements/<id>/state；GET /api/knowledge/requirements/<id>/history。
- GET /api/knowledge/inventory：资料根目录状态汇总。
- GET /api/forecast-products?q=海浪&date=2018-10-05&region=杭州湾；GET /api/forecast-products/<source_id>。
- POST /api/knowledge/model-test：开关启用后的固定文本连接检查，不发送业务资料。
- GET /api/knowledge/month1-acceptance；POST /api/knowledge/month1-acceptance/<id>/review：人工评定20题候选，提交时绑定候选与回答哈希。

在开发目录依次运行：

    ..\.venv\Scripts\python.exe -m pytest -q
    ..\.venv\Scripts\python.exe tools\check_month1_acceptance.py
    ..\.venv\Scripts\python.exe tools\build_month1_examples.py

check_month1_acceptance.py只读知识库并重生成回答记录；重新生成后须复核对应人工评分。样例构建工具发现已有人工标注时拒绝覆盖。固定文本API测试须另获授权再运行tools/check_model_connection.py --probe，会消耗模型额度。

电脑重启后运行start_phase1.ps1，保持终端运行；端口使用8767。此目录与旧部署包分开，当前仅完成本机可用版本，未同步浙江服务器。

# 网页正文阅读使用说明

## 如何使用

1. 打开“海洋灾害知识问答”首页，在“台风路径与历史案例”工具中检索并选择一个历史台风。
2. 确认右侧显示当前选中的台风，并在模型下拉框选择 DeepSeek。
3. 直接提出问题即可：系统先查本地结构化数据和 RAG，本地知识不足时自动联网、读取正文并总结。也可以明确提出联网核对要求，例如：

   - “联网搜索利奇马的官方资料，读取正文后总结。”
   - “搜索这个台风的官网资料，读取网页正文，按登陆过程、风暴潮和影响分别总结，并列出来源。”
   - “联网查找这个台风的灾情资料，读取正文后与本地知识库比较；无法核实的内容请说明。”

功能用于已选择台风后的连续问答，未选择台风时的普通聊天不走此流程。系统会使用当前选中台风的 SID、名称和年份约束检索，避免同名不同年资料混淆。请求等待期间会提示本地检索、必要时联网、正文读取和模型总结可能需要一些时间；该提示不是逐阶段实时进度。

## 工作范围

搜索获得候选页面后，优先读取官方来源，默认最多读取 3 页公开 HTTP(S) 网页。服务端提取网页主要正文，去除脚本、样式和导航等非正文内容，再将正文直接提供给模型，或分段阅读后汇总，用于生成回答。搜索摘要与读取到的正文分别标记，不把搜索摘要称为全文。

只访问可公开读取的页面，不使用登录凭据，不绕过登录、验证码、付费墙或站点访问限制。受限页面、超时、网络错误和不支持的格式会记录原因。动态页面、复杂排版、表格或附件可能无法完整提取；页面提取成功也不代表整页、附件和图片中的内容全部读到。

默认每页最多保留 48,000 个正文字符，超过限制会截断。页面下载、正文提取和模型分段阅读是不同环节：即使正文已提取，模型也可能只完成部分分段，或因模型调用失败而仅能使用搜索摘要。搜索或正文读取失败时，系统仍可使用可用的本地知识库证据回答，但应说明缺失的网页依据。

## 如何核对阅读记录

回答下方的“联网来源与阅读记录”逐页展示可点击标题及两类状态：

| 状态 | 含义 |
| --- | --- |
| 正文已提取 | 已获得页面主要正文，不保证整页完整提取 |
| 正文仅部分提取／已截断 | 仅取得部分内容，结论受此范围限制 |
| 正文读取失败／网页访问受限／页面格式不支持 | 未取得可用正文，展开记录查看原因 |
| 未尝试读取正文／正文读取已关闭 | 该来源没有执行正文读取 |
| 模型已读取提取正文 | 模型使用了提取后的正文，范围仍受提取限制 |
| 分段阅读 2/3（部分） | 3 个正文分段中只完成 2 个，不能称为全文已读 |
| 分段阅读 3/3（已汇总） | 已完成本次提取正文的分段阅读，再汇总作答 |
| 模型仅使用搜索摘要，未读取正文 | 即使网页已下载，也不能认定模型已读取正文 |
| 正文已提取，但模型总结未完成 | 正文提取成功，但最终模型调用未完成，不能认定模型已读取正文 |

“查看提取信息与节选”可展开原始链接、最终链接、提取字符数、读取时间、页面标注发布时间（若有）、正文 SHA-256、失败原因和最多 500 字符的正文节选。节选仅供核对，并非全部送入模型的内容。页面标题、错误信息和节选按纯文本显示；无效或非公开 HTTP(S) 链接不会启用点击。

来源记录能核对“读了什么、读到多少”，不能证明来源准确、信息最新或模型总结无误。请自行核对原网页、台风年份和发布时间；网页资料不能替代气象部门正式预警，也不能修改本地数值检索的台风路径排名。

## 配置与重启

在现有 `.env` 中使用以下默认配置，保留原有 DeepSeek 密钥，不需要更换或另填搜索 API 密钥：

```dotenv
TYPHOON_WEB_SEARCH_ENABLED=true
TYPHOON_WEB_SEARCH_PROVIDER=auto
TYPHOON_WEB_READ_ENABLED=true
TYPHOON_WEB_READ_TIMEOUT_SECONDS=12
TYPHOON_WEB_READ_MAX_PAGES=3
TYPHOON_WEB_READ_MAX_CHARS=48000
TYPHOON_WEB_SUMMARY_TIMEOUT_SECONDS=40
```

- `TYPHOON_WEB_SEARCH_PROVIDER=auto`：依次尝试 360 搜索、搜狗、必应中国站和百度，验证码或受限来源会被自动跳过；系统不会尝试绕过验证。
- `TYPHOON_WEB_READ_ENABLED`：是否读取搜索结果页面正文；关闭后仍可保留搜索摘要。
- `TYPHOON_WEB_READ_TIMEOUT_SECONDS`：单页正文读取的超时预算。
- `TYPHOON_WEB_READ_MAX_PAGES`：每次问答最多读取的网页数量。
- `TYPHOON_WEB_READ_MAX_CHARS`：单页提取正文的字符上限。
- `TYPHOON_WEB_SUMMARY_TIMEOUT_SECONDS`：模型正文阅读／分段总结的超时预算，不等于整个问答的总耗时。

正文读取还需要 `TYPHOON_WEB_SEARCH_ENABLED=true`，并且本地知识被判为不足或用户明确要求联网。自动模式需要允许访问 `www.so.com`、`www.sogou.com`、`cn.bing.com`、`www.baidu.com`，网络还需允许访问结果中的公开源站；实际可读范围取决于运行机器的网络条件。正文读取采用验证并固定公网IP的直接连接，不继承系统代理、登录Cookie或凭据，防止恶意链接访问内网；只能经代理上网的部署环境需另行配置受控出口方案。

新增配置在未填写时即使用上述默认值，现有 `.env` 不必重复添加。单次回答的总耗时还包括搜索、正文读取和最终模型生成；长文可能额外产生多次模型调用和相应费用。页面使用说明不承诺固定的总响应时间，接入外部网关时需要相应调整超时或改用异步接口。网页不会自动写入正式台风知识库。

修改 `.env` 后，使用当前已有的启动方式重启 `production_server.py` 才会生效。若原来通过 `deploy\windows\start.ps1` 启动，就停止旧服务后重新运行该脚本；若原来直接启动服务器，就沿用原命令和 Python 环境。无需重新部署，也不要同时启动多个占用同一端口的服务进程。

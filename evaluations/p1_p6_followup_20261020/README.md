# P1–P6 后续修复：公开离线证据包

本包用于代码评审和 Claude 后续方案讨论。**本轮没有调用模型、搜索网络或访问运行服务，也没有生成新版完整问答。** 旧模型最终回答、旧模型初稿原子、当前程序重判结果是三种不同产物。

| 文件 | 内容 |
|---|---|
| `deterministic_grounding.json` | 24盒录制的逐原子确定性重判；仅编号、哈希、规则与计数 |
| `deterministic_delivery_summary.json` | 同一批旧最终原子的子问交付重新分类；省略正文和完整重排答案 |
| `deterministic_scope_summary.json` | 缺项审查重放计数；省略原始请求、响应和缺项正文 |
| `public_case_examples.json` / `PUBLIC_CASES.md` | 5个只引用公开网页的典型片段及明确边界 |
| `verification_summary.json` | 私有源报告哈希、运行模块哈希、最终测试计数 |
| `verify_evidence.py` / `SHA256SUMS.txt` | 计数复核和交付文件完整性校验 |

**可复核的统计：** 24盒录制、40次逐原子审查；39次原始原子完全匹配，1次G1解析边界改变而要求新judge。重判保留434、删除174个原子；22个旧归纳判断缺少证明字段，继续拒绝。健康来源告警29→18，条款定位符误识别2→0；12个原子补回地方资料范围标签。173次整篇正文与哈希匹配，17次未匹配，不拼接摘段伪造正文。数字均为审查发生次数，**不是24题正确率**。

交付分类覆盖70个子问：旧标记54 full / 15 partial / 1 missing，重判为49 / 19 / 2。降低完整标签用于揭示漏答，不能解释成模型新答得更差或已补齐答案。缺项阶段重放40个输入，4题的初始保留缺项发生变化。最终本地测试为 **1485 passed + 102 successful subtests**，JUnit共1587项、零失败；测试通过也不等于业务验收。

运行 `python verify_evidence.py` 可离线核对本包内部统计及SHA256。取得原始私有录制的团队成员，才可用仓库 `tools/recheck_grounding_recordings.py` 重做39次阶段重判；公开仓库不附带这些录制，不能仅凭本包复现新的模型质量结果。

**解释边界：** `old_model_answer` 指历史完整回答，本包仅保留其哈希；`recorded_generation_atom` 是历史模型初稿片段；`new_stage_replay` 是当前规则对同一片段的处理。重排、补范围标签或拒绝错误“完整”标签都不是新模型回答。G1新边界、归纳证明生成、恢复后的再次检索和完整回答质量，仍须另行授权真实调用验证。

公开范围仅含政府/疾控/天气网页链接、必要短片段、问题、输出原子和哈希；没有密钥、账号、Cookie、令牌、会话标识、原始提示/响应、完整业务资料或本机绝对路径。网页内容反映录制时取得的版本，不代表已重新核验当前页面或法律效力。
